# Companion notebooks

This section supports the paper [*Online Stochastic Matching: A Polytope Perspective*][paper] and its follow-ups.

Its goal is to demonstrate how the results from these papers can be obtained using the [stochastic_matching package][package].

It contains in particular:

- demonstration of the use of the [package] for theoretical description (graph categorization, etc...);
- the production of all simulation-based results from the papers.

:::{warning}
This section is NOT intended to be self-contained. Please refer to the relevant paper for context and explanations.
:::
